Comparison methodology

Trustpilot values use the site’s external rating snapshot. Challenge terms use the lowest-priced tracked 100K, two-step entry for each selected firm. LENZ offers come from the current offer catalog. Payout figures use matching firm rows from the embedded payout snapshot; unavailable values remain an em dash.

Before choosing a firm

  • Confirm the current rules and eligibility with the firm.
  • Compare drawdown type as well as the headline price.
  • Treat payout volume as activity data, not a quality guarantee.

Compare Firms FAQ

Which challenge does the comparison use?

It uses the lowest-priced 100K, two-step challenge currently present in the site’s challenge dataset for that firm.

Why does a field show an em dash?

The site does not have a verified value for that firm and field. Missing values are never estimated.

Are payout totals a guarantee of future payouts?

No. They show tracked historical activity for the displayed snapshot and do not predict future results.

Can I compare more than four firms?

You can compare four at a time. Change any selector to review another firm without reloading the page.

How We Verify and Rank Firms

Prop Firm Lenz displays tracked blockchain payout records from the embedded payout dataset. Table totals and payout counts are ranked only from the selected timeframe, while Trustpilot scores remain a separate external snapshot.

  • Tracked records are not firm-submitted claims.
  • Missing payout metrics remain blank instead of being estimated.
  • Category counts include only firms that can be matched to the site’s firm directory.
  • Use payout history alongside current firm rules and verified reviews.
